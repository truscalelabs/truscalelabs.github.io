      What it fixes

      Everything happens on a copy in a temporary scene. Your own scene and .blend file stay as they were.

      Leftovers from the scene
      Removes cameras, lights, rigs, empties and animation. The current pose stays.
      Real-world size
      Converts from centimeters, millimeters, inches or feet, or scales the product to a height you enter.
      Orientation
      Turns the front toward the shopper and stands up a model that lies on its side. You choose both in the panel.
      Position
      Puts the lowest point on the floor and centers the product on the origin.
      Triangle count
      Reduces geometry only as far as the platform limit or file size target requires.
      Textures
      Resizes them, makes them square and power-of-two, converts them to PNG or JPEG, and creates missing base color and metallic-roughness maps.
      Geometry
      Applies modifiers and transforms, fixes mirrored parts and makes closed meshes single-sided.
      File size
      Exports again with smaller textures, then fewer triangles, until the file meets Shopify's 4 MB target.
      Final check
      Opens the finished GLB, checks it again and writes an HTML and a JSON report.

      A whole folder in one command

      Batch mode runs from a terminal, without Blender's window. Each model gets a GLB and a report, the folder gets a summary page, and the exit code tells your script whether everything passed.

      Questions

      Which Blender versions are supported?

      4.2 and newer. It is tested on 4.2, 4.5, 5.0 and 5.2. It uses the extension system introduced in 4.2, so it doesn't install in 4.1 or older.

      Will it change my scene or my .blend file?

      No. It works on a copy in a temporary scene and removes everything it created when it's done. Your objects, materials and images stay as they were.

      My Seller Central page shows different Amazon limits.

      Change them under Advanced limits, or with --max-triangles, --texture-max and --texture-min in batch mode. To set them once for everyone, use a COMMERCE_READY_PROFILES file (see Documentation).

      Does it send my models anywhere?

      No. It works fully offline. The only permission it asks Blender for is file access, to read your models and write the results.

      Can I use it in an automated pipeline?

      Yes. Batch mode runs without the interface, returns exit codes and writes a JSON report for each model plus a summary. The standalone checker needs only Python.

      Will you add other platforms?

      Version 1.0 covers Amazon and Shopify. Tell us which platform you need in the product's ratings or messages. That decides what comes next.
