Commerce-Ready 3D documentation

Version 1.0.0, for Blender 4.2 and newer. To try the checks on a file first, use the free checker.

Installation

  1. Download the ZIP file. Don't unpack it.
  2. In Blender, open Edit > Preferences > Get Extensions.
  3. Click the arrow in the top-right corner and choose Install from Disk, then pick the ZIP.
  4. Open the 3D Viewport sidebar (press N) and click the Commerce Ready tab.

Requires Blender 4.2 or newer. The add-on works offline and never connects to the internet.

Quick start

  1. Open or import your product model.
  2. In the Commerce Ready tab, choose the Platform: Amazon or Shopify.
  3. Select the product's objects. Child objects are included automatically.
  4. Press Check to see what fails without changing anything.
  5. Set the options below if needed, then press Make Ready and Export.
  6. Press Open Report to see the result, or Open Folder to find the GLB.

Panel options

Platform. The rules to check and fix against.

Objects. Selected uses the selected objects and their children. All visible uses every visible object in the scene.

Product front. The Blender view in which you see the front of the product: Front, Back, Right or Left. The add-on turns the product so its front faces the shopper.

Stand up. For models that lie on their side or back. Choose the rotation around X that makes the product upright: +90, -90 or 180 degrees. Press Check afterwards and look at the reported height.

Built in. The unit the model was made in: meters, centimeters, millimeters, inches or feet. Marketplaces read GLB files in meters, so a bottle built in centimeters would otherwise show up 26 meters tall. If your scene's unit scale isn't 1, the panel shows a warning as a reminder.

Real size. Instead of converting units, you can scale the product so that its height, width, depth or longest side equals a size you enter. Use this when you know the real product's dimensions.

One object. Shopify recommends a single object, so As recommended joins parts for Shopify and keeps them separate for Amazon. Join and Keep parts override that.

Output. The folder for the GLB and the reports. The default //commerce_ready/ means a folder next to your .blend file. Save the .blend first, or choose an absolute folder.

Advanced limits. Override the platform's triangle limit, largest and smallest texture size, and target file size. 0 keeps the platform default; -1 removes the limit.

Buttons

Check exports a temporary copy of the selection and checks it, without fixing anything. Use it to see where a model stands.

Make Ready and Export fixes the copy, exports the GLB, checks the finished file and writes the reports.

After either button, the panel shows the overall result, each check with its value, and the list of changes. Open Report opens the HTML report in your browser, and Open Folder opens the output folder.

Reading the result

  • Ready: every requirement passes.
  • Ready, with recommendations: the file will be accepted, but the platform recommends something more (for example one material per model on Shopify). The report says what.
  • Not ready: at least one requirement fails, and the note explains what to change. This usually happens when something can't be fixed automatically, such as a texture that can't be read.

The report also has a short Check by eye before upload list, for things software can't judge, such as whether the size matches the real product.

Batch mode

Run Blender from a terminal with the -c commerce_ready command:

blender -c commerce_ready --platform amazon --output ready/ models/
blender -c commerce_ready -p shopify -o ready/ --unit cm --join yes models/
blender -c commerce_ready -p amazon -o checks/ --check-only models/

On Windows, use the full path to blender.exe, for example "C:\Program Files\Blender Foundation\Blender 4.2\blender.exe" -c commerce_ready ....

Option Meaning
-p, --platform amazon or shopify (required)
-o, --output output folder (required)
-r, --recursive also search subfolders
--check-only check files without fixing or exporting
--front front, back, right or left: the view showing the product's front
--up-fix none, x90, x-90 or x180: stand up a lying model
--unit m, cm, mm, in or ft: the units the model was built in
--height, --width, --depth, --longest scale so this dimension equals the given meters
--join auto, yes or no
--max-triangles, --texture-max, --texture-min, --target-mb override platform limits
--jpeg-quality JPEG quality from 1 to 100 (default 90)
-q, --quiet print only the final summary

Supported input files: .glb, .gltf, .fbx, .obj, .stl, .ply, .usd, .usda, .usdc, .usdz and .blend.

The options apply to every file in the run, so put models that need different settings (for example, different units) in separate folders.

Each model gets name_platform.glb, name_platform.html and name_platform.json. The folder gets summary.html and summary.json.

Exit codes: 0 means every file is ready (recommendations are allowed), 2 means at least one file is not ready, and 1 means an error, such as a file that couldn't be opened.

Checking a GLB without Blender

The checker is plain Python 3 with no dependencies, so it can run on a server or in CI. Unzip the add-on ZIP into a folder, then run from that folder:

python glb_inspect.py model.glb --platform amazon
python glb_inspect.py model1.glb model2.glb --platform shopify --json

Changing platform limits for a whole team

Put the limits in a JSON file and point the COMMERCE_READY_PROFILES environment variable at it. The panel, batch mode and the checker all read it:

{"amazon": {"max_triangles": 100000, "texture_max": 2048}}

FAQ

Which Blender versions are supported?

4.2 and newer. It is tested on 4.2, 4.5, 5.0 and 5.2. It uses the extension system introduced in 4.2, so it doesn't install in 4.1 or older.

Will it change my scene or my .blend file?

No. It works on a copy in a temporary scene and removes everything it created when it's done. Your objects, materials and images stay as they were.

My product shows up huge or tiny. What do I do?

Set Built in to the units the model was made in, or use Real size and enter the product's real height. The report shows the final size in centimeters and inches so you can compare it with the real item.

The product faces the wrong way in the viewer.

Set Product front to the Blender view in which you see the front of the product. For a model lying on its back, use Stand up.

My Seller Central page shows different Amazon limits.

Change them under Advanced limits, or with --max-triangles, --texture-max and --texture-min in batch mode. To set them once for everyone, use a COMMERCE_READY_PROFILES file (see Documentation).

Why is the Shopify result "Ready, with recommendations"?

Shopify accepts the file, but its checklist recommends more, for example one material per model, or occlusion packed into the metallic-roughness texture. The report names each recommendation. They don't block the upload.

Does it use Draco or meshopt compression?

No. Files stay standard glTF so every viewer accepts them. File size is reduced through texture size, JPEG conversion and triangle count instead.

Can it reduce triangles without ruining my model?

It uses Blender's Decimate modifier and only reduces as much as the limit requires. For hero products where every edge matters, a hand-made low-poly version will look better. The add-on tells you when it reduced triangles and by how much.

Can I use it in an automated pipeline?

Yes. Batch mode runs without the interface, returns exit codes and writes a JSON report for each model plus a summary. The standalone checker needs only Python.

Does it send my models anywhere?

No. It works fully offline. The only permission it asks Blender for is file access, to read your models and write the results.

Will you add other platforms?

Version 1.0 covers Amazon and Shopify. Tell us which platform you need in the product's ratings or messages. That decides what comes next.

I found a model it handles badly.

Send us the HTML report and, if you can, the model. The report includes the Blender version, the platform profile and every step taken, which is usually enough to reproduce the problem.
